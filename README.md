# 🚀 Playwright Automation Framework

Production-ready UI & API Test Automation Framework built with Playwright and TypeScript.

---

## 📌 Project Vision

This repository demonstrates how a modern Playwright automation framework can be designed using enterprise software engineering principles.

The project focuses on building a scalable, maintainable and production-ready automation framework for UI and API testing.

The framework focuses on:

- Clean Architecture
- SOLID Principles
- Maintainable Test Design
- Reusable Components
- Scalable Project Structure
- Continuous Integration
- Reliable Test Execution

## 📂 Project Structure

src/
 ├── api          # API clients
 ├── components   # Reusable UI components
 ├── config       # Framework configuration
 ├── data         # Test data
 ├── fixtures     # Custom Playwright fixtures
 ├── pages        # Page Object Models
 ├── types        # TypeScript models
 └── utils        # Shared helper utilities

tests/
 ├── api
 └── e2e

## 🏗 Design Principles

This framework is built around the following engineering principles:

- Separation of Concerns
- Single Responsibility Principle
- Don't Repeat Yourself (DRY)
- Composition over Duplication
- Reusability
- Readability
- Scalability
- Maintainability
